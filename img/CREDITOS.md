# Fotos do site

## Como trocar uma foto

**Pelo painel (mais fácil):** entre em `/admin`, abra "Quartos" ou "Fotos", clique na foto e envie a nova.
O site é remontado sozinho em cerca de 1 minuto, já com as versões leves para celular e computador.

**Pelo código:** coloque a foto em `img/originais/` e aponte para ela no arquivo de `data/`
(`quartos.json`, `fotos.json` ou `pacotes.json`). Para ver localmente: `npm run dev`.

Dicas: fotos na horizontal, com pelo menos 1200px de largura (a capa, 1920px).
Escreva uma descrição para cada foto: ajuda pessoas cegas e o Google.
